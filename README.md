### Featured projects

**🔐 DocSeal** — cryptographic document protection system for CSIR-NPL calibration certificates. Field-level Merkle-commitment tamper detection, RSA-4096 signing, AES-256 encryption, Ethereum Sepolia blockchain timestamping. FastAPI backend, 37 passing unit tests.
`Python` `FastAPI` `Cryptography` `Blockchain` `Docker`

**📦 OpenDCS** — modular logistics decision-intelligence system benchmarking a trained Random Forest classifier against a rules-based FIFO engine, targeting a ~42% delay-reduction improvement. Live dashboard with SSE streaming.
`Python` `scikit-learn` `FastAPI` `PostgreSQL` `Docker` `GitHub Actions`

**🗺️ FRA Atlas** — full-stack decision support system combining dual-path OCR, hybrid NER, and a RAG layer over async FastAPI.
`Python` `FastAPI` `OCR` `NER` `RAG`

**💬 Wikipedia RAG Chatbot** — retrieval-augmented Q&A chatbot over Wikipedia content with a FAISS vector store.
`LangChain` `FAISS` `Streamlit`

**🤖 Autonomous Rover** — vision-guided rover combining an ESP32 microcontroller, Raspberry Pi, and OpenCV for real-time navigation.
`ESP32` `Raspberry Pi` `OpenCV`
